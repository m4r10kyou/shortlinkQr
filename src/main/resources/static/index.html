shortlinkQr

A URL shortener whose QR codes can be re-pointed after they are printed.

The QR code encodes the short link, not the destination. Change where the link points and every code already printed follows, with no reprint.

This is a backend service. There is no web interface — the endpoints below are the product, and this page exists so that the root of the domain says something useful instead of returning an error.

Try it

curl -X POST https://shortlinkqr.onrender.com/api/links \
  -H 'Content-Type: application/json' \
  -d '{"targetUrl":"https://example.com"}'

The response carries the short URL and a management token, shown once and never again. That token is what authorises later edits to the link.

Endpoints

POST /api/links
Create a link. Optionally with a custom alias and an expiry date.
GET /{code}
The public redirect. Counts a visit and sends the caller to the destination.
GET /api/links/{code}/qr
The QR code as a PNG, generated on demand and never stored.
PATCH /api/links/{code}
Re-point the link or change its expiry. Requires the management token.
POST /api/links/{code}/logo
Place a logo at the centre of the symbol. Requires the management token.
GET /api/health/ping
Liveness. Answers without touching anything.

Note

This runs on free hosting and goes to sleep when nothing is using it, so the first request after a quiet spell can take a few seconds.
